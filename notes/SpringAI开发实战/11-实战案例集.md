## 1. 流式敏感词打码：SensitiveWordStreamAdvisor

（完整讲解见 02 章）逐片改写模型输出，手机号打码：

```java
public class SensitiveWordStreamAdvisor implements StreamAdvisor {

    private static final Pattern SENSITIVE = Pattern.compile("1[3-9]\\d{9}");

    @Override
    public Flux<ChatResponse> adviseStream(AdvisedRequest request, StreamAdvisorChain chain) {
        return chain.next(request).map(this::filterChunk);
    }

    private ChatResponse filterChunk(ChatResponse response) {
        Generation gen = response.getResult();
        String text = gen.getOutput().getText();
        if (text == null) return response;
        String masked = SENSITIVE.matcher(text).replaceAll("1**********");
        Generation maskedGen = new Generation(
                new AssistantMessage(masked, gen.getOutput().getMetadata()),
                gen.getMetadata());
        return ChatResponse.builder().from(response).generations(List.of(maskedGen)).build();
    }

    @Override public int getOrder() { return Ordered.LOWEST_PRECEDENCE - 100; }
    @Override public String getName() { return "SensitiveWordStreamAdvisor"; }
}
```

生产升级点：跨 chunk 缓冲（敏感词可能被切在两片之间）。

## 2. 质量门重问：QualityGateAdvisor

（完整讲解见 03 章）回答太短就重问，带保险丝：

```java
public class QualityGateAdvisor implements CallAdvisor {

    private final int minWords;
    private final int maxRepeatAttempts;

    private QualityGateAdvisor(int minWords, int maxRepeatAttempts) {
        this.minWords = minWords;
        this.maxRepeatAttempts = maxRepeatAttempts;
    }

    @Override
    public AdvisedResponse adviseCall(AdvisedRequest request, CallAdvisorChain chain) {
        CallAdvisorChain subChain = chain.copy(this);
        AdvisedRequest current = request;
        int attempts = 0;
        while (true) {
            AdvisedResponse response = subChain.next(current);
            String text = response.response().getResult().getOutput().getText();
            int words = text == null ? 0 : text.split("\\s+").length;
            if (words >= minWords || attempts >= maxRepeatAttempts) {
                return response;
            }
            attempts++;
            current = AdvisedRequest.from(current)
                    .userText(current.userText()
                        + "\n\n（上一次回答过于简短，请给出不少于 " + minWords + " 个词的详细回答）")
                    .build();
        }
    }

    @Override public int getOrder() { return 0; }
    @Override public String getName() { return "QualityGateAdvisor"; }

    public static Builder builder() { return new Builder(); }
    public static class Builder {
        private int minWords = 20;
        private int maxRepeatAttempts = 3;
        public Builder minWords(int v) { this.minWords = v; return this; }
        public Builder maxRepeatAttempts(int v) { this.maxRepeatAttempts = v; return this; }
        public QualityGateAdvisor build() { return new QualityGateAdvisor(minWords, maxRepeatAttempts); }
    }
}
```

## 3. 压缩式记忆：SummarizingChatMemory

（完整讲解见 08 章第 6 节）三段式：system → [历史摘要] → 最近 N 条；超窗把最旧的滚进摘要。

```java
public class SummarizingChatMemory implements ChatMemory {

    private final ChatMemoryRepository repository;
    private final ChatModel summarizer;   // 裸 ChatModel，别挂记忆 Advisor
    private final int maxMessages;
    private final int retainRecent;

    public SummarizingChatMemory(ChatMemoryRepository repository,
                                 ChatModel summarizer,
                                 int maxMessages, int retainRecent) {
        this.repository = repository;
        this.summarizer = summarizer;
        this.maxMessages = maxMessages;
        this.retainRecent = retainRecent;
    }

    @Override
    public synchronized void add(String conversationId, List<Message> messages) {
        List<Message> all = new ArrayList<>(repository.findByConversationId(conversationId));
        all.addAll(messages);
        if (all.size() > maxMessages) {
            List<Message> toSummarize = all.subList(0, all.size() - retainRecent);
            String summary = summarize(toSummarize, findExistingSummary(all));
            List<Message> kept = new ArrayList<>();
            kept.add(new SystemMessage("[历史摘要] " + summary));
            kept.addAll(all.subList(all.size() - retainRecent, all.size()));
            all = kept;
        }
        repository.saveAll(conversationId, all);
    }

    @Override
    public synchronized List<Message> get(String conversationId) {
        return repository.findByConversationId(conversationId);
    }

    @Override
    public synchronized void clear(String conversationId) {
        repository.deleteByConversationId(conversationId);
    }

    private String summarize(List<Message> old, String existingSummary) {
        StringBuilder sb = new StringBuilder();
        if (existingSummary != null) sb.append("已有摘要：").append(existingSummary).append("\n");
        sb.append("请把以下对话压缩成简洁摘要（保留事实、决定、待办）：\n");
        for (Message m : old) {
            sb.append(m.getMessageType()).append(": ").append(m.getText()).append("\n");
        }
        return summarizer.call(new Prompt(sb.toString()))
                .getResult().getOutput().getText();
    }

    private String findExistingSummary(List<Message> all) {
        return all.stream()
                .filter(m -> m.getMessageType() == MessageType.SYSTEM
                        && m.getText() != null && m.getText().startsWith("[历史摘要]"))
                .map(m -> m.getText().substring(5))
                .findFirst().orElse(null);
    }
}
```

```java

    .defaultAdvisors(MessageChatMemoryAdvisor.builder(memory).build())
```

## 4. 多数据源装配

（讲解见 08 章第 7 节）业务库 @Primary + 记忆库手动 Bean：

```java
@Configuration
public class DataSourceConfig {

    @Bean @Primary
    public DataSource businessDataSource(...) { /* 业务库 */ }

    @Bean
    public DataSource memoryDataSource(...) { /* 记忆库 */ }

    @Bean @Primary
    public JdbcTemplate businessJdbcTemplate(...) { ... }

    @Bean
    public JdbcTemplate memoryJdbcTemplate(...) { ... }

    @Bean
    public ChatMemoryRepository chatMemoryRepository(JdbcTemplate memoryJdbcTemplate) {
        return JdbcChatMemoryRepository.builder()
                .jdbcTemplate(memoryJdbcTemplate)
                .dialect(new PostgresChatMemoryRepositoryDialect())
                .build();
    }
}
```

## 7. 用户自控工具循环（模式③）

```java
OpenAiChatOptions options = OpenAiChatOptions.builder()
    .internalToolExecutionEnabled(false)
    .build();

List<Message> history = new ArrayList<>(List.of(new UserMessage("北京天气如何？")));
Prompt prompt = new Prompt(history, options);

while (true) {
    ChatResponse response = chatModel.call(prompt);
    AssistantMessage output = response.getResult().getOutput();
    if (output.hasToolCalls()) {
        history.add(output);
        for (ToolCall toolCall : output.getToolCalls()) {
            String result = myExecute(toolCall);
            history.add(new ToolMessage(toolCall.id(), result));
        }
        prompt = new Prompt(history, options);
    } else {
        history.add(output);
        break;
    }
}
```

与 ChatMemory 联用时，中间消息手动入库：`memory.add(conversationId, List.of(output, toolMessage))`。

## 8. 参数增广：AugmentedToolCallbackProvider

```java
record AgentThinking(String innerThought) {}

AugmentedToolCallbackProvider<AgentThinking> provider = AugmentedToolCallbackProvider
    .<AgentThinking>builder()
    .toolObject(new MyTools())
    .argumentType(AgentThinking.class)
    .argumentConsumer(event -> log.info("Tool: {} | Reasoning: {}",
            event.toolDefinition().name(), event.arguments().innerThought()))
    .removeExtraArgumentsAfterProcessing(true)
    .build();

ChatClient chatClient = ChatClient.builder(chatModel)
    .defaultToolCallbacks(provider)
    .build();
```

```sql
CREATE TABLE IF NOT EXISTS SPRING_AI_CHAT_MEMORY (
    conversation_id VARCHAR(36) NOT NULL,
    content TEXT NOT NULL,
    type VARCHAR(10) NOT NULL CHECK (type IN ('USER', 'ASSISTANT', 'SYSTEM', 'TOOL')),
```
