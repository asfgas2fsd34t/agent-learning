# 06 多模态

> 来源：Spring AI 官方文档 `api/multimodality.html`（1.1.x）。

## 学习目标

- 理解多模态消息 = 文本 + Media 附件
- 掌握 Media 的构造（MimeType + 资源/URL/Base64）
- 了解各模型支持的媒体类型差异

## 1. 核心心智模型

```text
多模态 = UserMessage 里除了文本还可以带 Media（图片、音频、视频、PDF）
Message.content → 多模态消息 → ChatClient → 模型
能不能理解取决于模型能力（GPT-4o 看图、Whisper 听音频等）
```

## 2. Media 与多模态消息

```java
// 从 classpath 加载图片
UserMessage message = new UserMessage("这张图片里有什么？",
    new Media(MimeTypeUtils.IMAGE_PNG, new ClassPathResource("multimodal/test.png")));

// 从 URL
Media fromUrl = new Media(MimeTypeUtils.IMAGE_JPEG,
    URI.create("https://example.com/photo.jpg"));

// 从 Base64
Media fromBase64 = new Media(MimeTypeUtils.IMAGE_PNG, base64EncodedString);
```

## 3. 通过 ChatClient 调用

```java
String description = chatClient.prompt()
    .user(u -> u.text("描述这张图片，并列出其中的商品")
                .media(MimeTypeUtils.IMAGE_PNG, new ClassPathResource("shelf.png")))
    .call()
    .content();
```

## 4. 底层 API

```java
ChatResponse response = chatModel.call(new Prompt(
    new UserMessage("这张图片里有什么？",
        List.of(new Media(MimeTypeUtils.IMAGE_PNG, new ClassPathResource("test.png"))))
));
```

## 5. 各家模型支持情况（以实际服务文档为准）

| 模型 | 图片 | 音频 | 视频 |
|------|------|------|------|
| OpenAI GPT-4o 系列 | ✅ | 部分 | ❌ |
| Anthropic Claude | ✅ | ❌ | ❌ |
| Google Gemini | ✅ | ✅ | ✅ |
| Ollama 本地 | 看具体模型 | ❌ | ❌ |

## 6. 生产边界

- MimeType 要标对（IMAGE_PNG / IMAGE_JPEG），有的模型按 MIME 决定处理方式
- 图片体积大 → 注意 token 成本与请求大小限制；必要时先压缩
- 从用户上传拿资源时校验类型与大小，防止恶意大文件
- URL 方式注意内网 SSRF 风险（用户可控 URL 时）
