# LangGraph 开发实战

本目录将原始 LangGraph 长篇课程内容按一级主题整理为 13 篇浓缩笔记。每篇保留核心概念、执行流程、关键 API、最小代码和生产注意事项，删除重复解释、超长运行输出与同类截图，建议按编号顺序学习。

## 学习顺序

| 序号 | 主题 | 学习重点 |
| --- | --- | --- |
| 01 | [LangGraph 总览](01-LangGraph总览.md) | 定位、核心元素、运行流程、Graph API 与 Functional API |
| 02 | [图的基础构建与运行](02-图的基础构建与运行.md) | 定义、编译、调用和可视化一张图 |
| 03 | [图的状态管理](03-图的状态管理.md) | State、Reducer、Schema、MessagesState |
| 04 | [控制流](04-控制流.md) | 顺序、分支、并行、循环、Map-Reduce 和递归限制 |
| 05 | [节点执行与容错机制](05-节点执行与容错机制.md) | 重试、超时、异常处理、缓存和全局配置 |
| 06 | [持久化机制与可恢复执行](06-持久化机制与可恢复执行.md) | Checkpoint、历史快照、故障恢复、时间旅行、PostgreSQL |
| 07 | [图记忆管理](07-图记忆管理.md) | 短期记忆、长期记忆、Store 和 Runtime Context |
| 08 | [中断](08-中断.md) | interrupt、恢复执行、动态中断和静态断点 |
| 09 | [项目部署](09-项目部署.md) | 本地部署、LangSmith 和 Agent Chat UI |
| 10 | [工具调用节点](10-工具调用节点.md) | ToolNode、ToolRuntime、状态更新和错误处理 |
| 11 | [流式执行](11-流式执行.md) | stream、astream、流模式和事件流 |
| 12 | [子图](12-子图.md) | 子图嵌入、持久化、流式输出和动态路由 |
| 13 | [运行图设计模式](13-运行图设计模式.md) | 提示链、并行、路由、工作流、评估优化和 Agent 循环 |

## 补充说明

- PostgreSQL 部署与配置附录归入第 06 篇，和持久化内容放在一起学习。
- 笔记中的代码以当前项目安装的 LangGraph API 为准，升级版本后应重新核对方法签名。
- 原始长篇材料仍保留在外部课件目录，本目录只维护适合复习和实践的精简版本。
